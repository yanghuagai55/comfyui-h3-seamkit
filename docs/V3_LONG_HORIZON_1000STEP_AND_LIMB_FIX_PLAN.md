## 一、深度诊断：为什么高速动作会出现「肢体错位」？（四大物理根因）

通过对 `v2.8` 与 `v2.9` 同源双人剑戟视频逐帧解剖（尤其 `f084` 腾空旋身帧），肢体错位并非单一噪点问题，而是由**四层机制叠加**造成：

1. **一采（Pass-1）与二采（Pass-2）的职责边界断层（最核心根因）**
   - 在两阶段流水线中，**骨骼拓扑、四肢连接关系、武器握持轴向与前后遮挡顺序在 Pass-1（`sigma: 1.00 → 0.55`）就已经 95% 锁死**；
   - `v2.9` 仅训练了 Pass-2 区间（`sigma ∈ [0.14, 0.75]`，输入为上采样 `z_up`）。一旦一采（4 步 Turbo + 稀疏注意力）在高速旋转帧生成了「左腿拧成右腿」或「裙下多出第三条小腿」的潜变量骨架，二采保锐 LoRA 不仅无法扭转错位骨架，反而会把错误的肢体轮廓**进一步锐化描边**！
2. **三视图原图直喂引发的「正背双视角拼合幻觉」（3-View Multi-Limb Confusion）**
   - 本地角色设定集（如 `D:\工作空间\创作\veo` 下的三视图）普遍在单张 `<Picture>` 中并排包含 **正面 + 侧面 + 背面三个完整全身像（共 6 条手臂、6 条腿、3 个头、3 条尾巴）**；
   - 在高速转身动作帧中，视频 Query 块在稀疏路由时若同时高权重命中参考图左侧「正面躯干」与右侧「背面双腿」，Attention Value 凸组合就会直接在画面里拼出 **「上半身朝前、下半身朝后 180° 反折」或「多肢体残影」**！
3. **教师样本池缺乏「解剖学淘汰门禁」（Garbage-In 传递）**
   - 此前教师采集仅按 `LapVar` 清晰度过滤，未剔除 20B 基座自身在大动态下偶发（约 `20%–30%` 概率）的四肢穿模/断剑废片；哪怕只有 15% 教师潜变量含错位肢体，长程训练也会把错误拓扑学进权重。
4. **缺少时间速度场连续性约束（$\Delta_t v$）与长程 EMA 稳态收敛（`140 步` 欠收敛）**
   - 此前 `140 步` 仅相当于在 90 条样本上走了约 `1.5` 轮，新增的 32 个高动态 Attention 秩范数（`0.45`）尚未完全展开；且损失函数仅有单帧空间梯度 $\|\nabla_{xy} v - \nabla_{xy} v^*\|_1$，缺少跨帧运动流雅可比项 $\|\Delta_t v - \Delta_t v^*\|_1$，无法惩罚相邻帧关节跳变与断剑瞬移。

## 三、根治肢体错位的三大算法升级

### 1. 一采 + 二采「双段全覆盖」协同蒸馏（打通高噪骨骼区 $\sigma \in [0.60, 0.96]$）
不再只救二采末端，把训练拆为职责分明的两套协同权重（或统一全噪声域条件权重）：
- **高噪骨骼拓扑段（Kinematic Anchor，$\sigma \in [0.55, 0.96]$，服务一采与二采首步）**：
  - 重点训练模型在低分辨率/高噪起步期锁定**正确四肢数量、左右手脚拓扑、长柄武器（如 `Grok` 战斧 / 双人长剑）刚体共线性**；
- **中低噪精修锁锐段（Detail & Ink-Line Polish，$\sigma \in [0.12, 0.60]$，服务二采后两步）**：
  - 专注发丝分缕、瞳孔高光、衣褶蕾丝与赛璐璐墨线锐度。

### 2. `Best-of-3` 黄金教师解剖学筛选流水线（Stage 0 数据提纯）
算力充沛时，**教师质量上限决定千步收敛上限**。对每条高难度动作提示词（扩充至 **`240` 条黄金动作矩阵**：涵盖 7 角色单人武技、双人交锋、空中转体、蓄力施法、Q 版跳跃，覆盖 `22f / 39f / 73f` 三种时长）：
1. 用 28–32 步满血稠密 BF16 教师（`DaSiWa` / `Singularity` 二次元教师底座，零写实运动模糊）每条跑 **`3` 个不同随机种子**；
2. 自动计算三项门禁指标并**只保留综合分最高且达标的 Top-1 入库**：
   - **光流双向一致性误差（Forward-Backward Optical Flow Occlusion Consistency）**：揪出帧间肢体瞬移、断裂与凭空多腿；
   - **刚体边缘直线度 & 高速帧 Tenengrad 锐度比**：确保刀剑斧柄不弯曲成面条；
   - **色彩低频守恒度**：确保无局部过曝坏块。

### 3. 时空运动流连续性损失（Temporal Velocity Jacobian Loss）+ EMA 权重平滑
在 `train_h3_lora.py` 中升级千步级复合目标函数：

$$\mathcal{L}_{v3} = \|v_\theta - v_{\text{ref}}^*\|_2^2 + \lambda_{xy} \|\nabla_{xy} v_\theta - \nabla_{xy} v_{\text{ref}}^*\|_1 + \lambda_t \left\| M_{\text{mot}} \odot (\Delta_t v_\theta - \Delta_t v^*) \right\|_1 + \lambda_{\text{orth}} \|A_{\text{new}} \hat{A}_0^\top\|_F^2$$

其中 $\Delta_t v[:, :, t] = v[:, :, t+1] - v[:, :, t]$ 为潜空间时间一阶差分：
- 当角色处于高速挥砍/旋身区（$M_{\text{mot}} \to 1$）时，$\lambda_t = 0.20$ 强力约束学生预测的相邻帧速度变化率严格贴合黄金教师，**从物理上封死单帧关节反折与多肢体闪烁**；
- 同时引入 **`grad_accum = 2~4`**（消除 `batch=1` 单样本梯度抖动，这也是千步精细收敛的关键！）与 **`EMA (decay = 0.995)` 指数滑动平均权重导出**，彻底解决 600–1,000 步后期高频细节震荡问题。
