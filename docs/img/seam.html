① 硬切
hunt 测到真转镜正压在边界
窗口 A
窗口 B
重叠 0：B 从边界处全新生成。
内容本来就该在这一帧断 → 看不出接缝 ✓
要求：提示词里这一帧必须写了换镜头
② 冻结锚定（默认）
hunt 拒绝 / calm 挪过界
窗口 A
A 的前缀
B 新生成
重叠 17 帧：前缀逐字取 A 的输出 → 零重影 ✓
代价：那 17 帧的"A | B"交界仍是一次硬接——两窗背景画得不一样时表现为跳变
③ 交叉淡化 seam_blend=true
静止 / 慢速镜头
窗口 A
A→B 线性溶解
重叠区内两窗 latent 按 0→1 线性混合再解码 → 跳变被摊成柔和过渡 ✓
运动镜头风险：两窗差异大 → 重影 / 糊团
窗口 A 生成 A 的前缀（逐字冻结） 窗口 B 生成
怎么选：动作/运镜剧烈的片 → 冻结（②）；对话/静态镜头 → 交叉淡化（③）；提示词切点极准、想要干脆的剪辑 → 硬切（①，overlap_frames=0）。 判据不是"哪个更高级"，而是两个窗口在重叠区画得像不像——像 → 淡化；不像 → 冻结或硬切。
