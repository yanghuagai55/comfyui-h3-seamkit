hunt 与 calm · 一条缝怎么定形

每个计划切点独立走一遍这条流程；两个搜索都只看一采 latent（不用 VAE，秒级）
HUNT —— 找"模型真正换镜头的那一帧"
① 变化剖面
一采 latent 逐 token 算变化量（全局变化 与 jerk 取更差者）
② 在 ±hunt_search_window 内取最大峰
转镜 = 整片最剧烈的 latent 变化
③ 两道门禁
持续性 ≥ hunt_min_persistence（0.8）
真切断要"留在别处"；闪烁/抖动过不了

转镜置信 ≥ 2.0（内置）
防"锁定镜头里的姿势跳变"被误判为转镜
④ 通过 → 吸附到最近 17k 帧 → 硬切
残差 ≤ seam_tolerance_frames 才算"压在转镜上"
➜
CALM —— hunt 不可靠时怎么放这条缝
① 在 ±calm_search_window 内找最安静的 17k 独占帧
用同一份剖面；profile_camera_compensate 可先把纯运镜抵消
② 四道门（任一不过就退回计划点）
calm_min_gain 0.15 —— 候选要比计划点安静 ≥15%
calm_too_quiet_below 0.05 —— 过于静止不动（防顿挫）
calm_min_quality 0.8 —— 仍不够安静 → 退回硬切
calm_abstain_below 0 —— 整片太平淡 → 全程不搜
③ 落缝策略（calm_policy）——按片子类型选
calm_overlap（默认，静态/对话片）
挪到最平缓的独占帧 + 给锚定 overlap

jerk_hardcut（动作/运镜剧烈片）
反过来挪到 jerk 最猛处：burst = jerk[t−5]+jerk[t]+jerk[t+5]（3-token 窗，防单点尖峰）
→ 硬切、不锚定。运动把切藏起来；且高 jerk 处模型本就在糊，两窗锐度台阶最小
为什么这样分工：hunt 回答"这里能不能硬切"——它对就一刀下去，接缝消失在内容本该断的地方； hunt 拿不准时，calm 回答"那挪到哪儿最不容易被看见"。两者都靠一采 latent 的同一份变化剖面，零额外显存。
