指纹边界在哪：一采的缓存指纹 = 它上游子图的哈希。上游 Plan 全在指纹里， 所以"画布 / 每段秒数 / 缓存开关"必须放上游；下游 Plan 在指纹之外，33 个控件随便改。
缝怎么处理：hunt 找到真转镜 → 硬切；找不到 → calm 挪到最平缓独占帧 + 锚定 overlap； 动作里的缝则反过来藏进最猛处。三种缝由 calm_policy=auto 逐缝自动挑。
