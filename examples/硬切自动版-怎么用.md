# 硬切工作流 · 怎么用（自动版）

> 示例工作流：**`examples/硬切自动版.json`**（与本文同目录）
> 本插件：GPL-3.0-or-later
> 这份只讲**怎么用**。原理与参数细节见插件目录 `MANUAL.md`；提示词模板 `templates/hardcut-prompt-template.md`。

---

## 0. 准备

1. 把 `comfyui-h3-seamkit` 放进 `ComfyUI/custom_nodes/`，**重启 ComfyUI**
2. 需要：ComfyUI ≥ 0.30（H3 原生节点）+ MiniMax H3 模型（ref2va DiT / Qwen3-VL 文本编码器 / video + audio VAE）
3. 打开 `硬切自动版.json`

---

## 1. 三步跑起来

### ① 写提示词 → `#9 Input Text (Prompt)`

按六段结构写（模板见 `templates/hardcut-prompt-template.md`）。**最关键一句**：

```
summary: a 3-shot sequence with hard cuts at 00:04.958, 00:09.917, ...
```

**绝对不能出现** `one continuous take` / `no cuts` / `unbroken` —— 模型会抵抗切点。

### ② 定切点 → `#56 ★ 自动硬切总控`

| 参数 | 填什么 |
|---|---|
| 时长（秒） | 例 `15`（自动吸附到 17n+5 帧栅格） |
| `cut_1` ~ `cut_4` | 切点秒数，**必须是 0.7083s 的整数倍**（17 帧）；用不到的槽填 `-1` |
| `chunk_step` | `0` = 自动；手动每 ±1 = 每窗 ±17 帧 |
| 一采画布 MP | `0.4`（864×480）—— 管结构 |
| 二采画布 MP | `1.5`（1664×928）—— 管细节，**要提画质优先提这个** |

**切点拿不准就先算**（零依赖，秒出）：

```
python <你的ComfyUI>/custom_nodes/comfyui-h3-seamkit/hardcut_math.py 15 "4.25,8.5,12.75" --mp 1.5
```

输出里的 **`chunk ladder`** 每档一行：切几刀、切在哪、负载、尾段是否合法。

**15 秒常用档（1.5MP）**

| 段数 | 切点填 | 窗口帧数 | 负载 |
|---|---|---|---|
| 2 段 | 7.792 / -1 / -1 / -1 | [187, 175] | 280.5 ⚠️ OOM |
| 3 段 | 4.958 / 9.917 / -1 / -1 | [119, 119, 124] | 191.5 ✅ |
| 4 段 | 4.25 / 8.5 / 12.75 / -1 | [102, 102, 102, 56] | 157.5 ✅✅ |

### ③ Queue → 看报告

报告有三处（同一份内容）：`#57` / `#60` 预览节点，以及直接印在 `#56` 上。

**跑之前只确认一行**：

```
load estimate : 124f x 1.544MP = 191.5  (SAFE, 0.91x pass anchor)
```

- `SAFE` → 直接跑
- `LIKELY-OOM` → **加一处切点**（切短最长段）或降二采 MP

> 8GB 显存经验线：**≤ 210 通过，≥ 236 爆**。

## 2. 参数在哪（别改错节点）

| 要改什么 | 节点 |
|---|---|
| 提示词 | `#9 Input Text (Prompt)` |
| 时长 / 切点 / chunk_step / 两画布 MP | `#56` |
| 一采步数、shift | `#30`（turbo 底模下 `video_steps` 固定 4，调高白跑） |
| 二采步数 / denoise | `#39`（`3` / `0.30`） |
| 保存目录、文件名前缀 | `#77 VHS_VideoCombine` |
| 参考图（角色） | `#3` `#4` `#6` LoadImage |

---

## 3. 提示词硬规则（校验器/执行器会拦）

1. 六段结构齐全，`[Shot N]` 从 1 连续编号
2. `[Shot 2]` 起每段以 `At MM:SS.mmm,` 开头，**时间戳逐字等于切点**
3. 不能有 `no cuts` / `continuous take` / `one take` / `unbroken` / `no edit`
4. `retention_analysis` 要列出**全部** `[Shot N]` —— 角色跨切点不变脸靠它
5. 各镜**动作线连续**，只有机位/景别改变
6. 镜头数要和切点数对得上（3 镜头 ↔ 2 个切点）

---

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 切点处像"崩了"不像剪辑 | `[Shot N]` 换个**明显不同的机位**（过肩 / 仰角 / 大特写），别只挪一点景别 |
| 切完角色长相变了 | `retention_analysis` 补上切点**之后**的镜头 |
| 模型不切、画面拖着 | `summary` 里"一镜到底"的表述没删干净 |
| 报形状契约错误 | 高/低清 conditioning 的画布必须与 `#56` 同源（别手填） |
| OOM / 掉速 | 看报告 `load estimate`；加切点或降二采 MP；`it/s` 掉速 = 开始换页了 |
| 切点处声音断了 | **正常** —— 音频是一采整片透传，不随视频硬切 |
| 尾段太短报错 | 尾段需 ≥ 48 帧（2s）；把最后一刀往前挪或减少段数 |

---

## 5. 一句话原理（想深究再看 MANUAL.md）

接缝治不好就不治了 —— 执行器在指定帧**硬切**（`overlap = 0`，零混合），提示词让模型**在同一帧切镜头**：
两边对齐，缝就消失了，因为它变成了剪辑。顺带每段变短，峰值显存也跟着降。
